# MEXT Forge

App offline de inglés para el examen de la beca MEXT (15 jul 2027): detectar errores (Sección III), completar estructuras, errores persistentes y tracker de puntos ciegos.

**App:** https://matw1.github.io/mext-forge/ — en Chrome del celular: ⋮ → «Instalar app».

## Actualizar
1. Edita `../mext-forge.html`.
2. `node build.js` (regenera `index.html` y sube la versión del caché).
3. Commit y push.

`make-icons.js` regenera los íconos.
